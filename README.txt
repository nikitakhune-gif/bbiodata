BIODATA WEBSITE – अश्विनी बंडु खुणे

Files:
  index.html   -> biodata page
  style.css    -> design
  images/photo.webp -> new photo (background removed)
  qr.html      -> QR code generator

VS Code madhe kasa pahaycha:
  1. Folder VS Code madhe open kara
  2. "Live Server" extension install kara -> index.html var right-click -> Open with Live Server

Scanner (QR) saathi:
  1. Folder Netlify Drop (app.netlify.com/drop) var drag-drop kara, kinva GitHub Pages vapra
  2. Milalela link qr.html madhe paste kara -> QR download kara
  3. To QR scan kela ki biodata phone var open hoil
